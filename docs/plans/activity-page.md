# Activity Page idea

## About the Activity Page
- We need to rename the "Needs Attention" menu item to "Activity"
- The Activity menu label will show a badge ("3") for the number of changes for the current date.
- Activity will be page to show all of the changes in the system for a selected date.
- Activity page will list all of the Oracle tables from A-Z.
- There will be Date picker, Search box to filter tables and a tab with All | Created | Updated to filter.
- If someone clicks on "view", a panel will slide in from the right that shows the details for that Oracle table (title, date at a minimum).

Each string is SEGMENT1-SEGMENT2-SEGMENT3-SEGMENT4-SEGMENT5-SEGMENT6-SEGMENT7 from the extract — e.g. 04-6570-862-529-1488-0840-000. Segment 4 is the object code, segment 5 the project level, segment 6 the cost centre. Each code is tinted by what has been posted to it: pale yellow when purchase-order lines carry the combination, pale blue when it exists in the ledger with nothing posted against it yet. The badge on the code is its purchase-order line count. Click any code to read those lines. Click the selected month again to clear it.
Empty months are shown, not skipped.

How claiming works

  1. You pick a row, not a sentence. Typing only filters the list. The submit button stays disabled until a row is chosen, so no combination can be half-typed into existence.
  2. The server derives the project code. CC-0523-527 for the highlighted row — level then anchor object. It is never editable and never client-constructed.
  3. Future extracts bind automatically. The next Oracle run resolves each PO line to a combination key and attaches the matching rows to this project. No manual re-linking after day one.
